# homebrew-tap

ClaudeSeo's apps, distributed through Homebrew and GitHub Releases.

## MongoDB Grep

Native MongoDB client for running queries and exporting audit-ready Excel. Requires Apple silicon and macOS 26 or later.

```bash
brew install --cask ClaudeSeo/tap/mongodb-grep
```

## Portress

Menu bar list of listening TCP ports and their owning process or container. Requires Apple silicon and macOS 26 or later.

```bash
brew install --cask ClaudeSeo/tap/portress
```

## Lingo

Chrome extension that shows translations under the original web text, using the AI endpoint you configure.

Download the ZIP from [Releases](https://github.com/ClaudeSeo/homebrew-tap/releases/tag/lingo-v0.1.0) and follow the install steps in the release notes.
